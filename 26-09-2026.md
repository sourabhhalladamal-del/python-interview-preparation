# Python Interview Questions and Answers

## Basics

1. **What is Python?**

	Python is a high-level, general-purpose programming language. Its readable syntax supports scripting, automation, web development, data analysis, machine learning, and many other tasks. CPython, the standard implementation, compiles source code to bytecode and executes it on the Python virtual machine.

2. **What are Python's main features?**

	- Readable, relatively concise syntax.
	- Dynamic typing and automatic memory management.
	- Multiple programming styles: procedural, object-oriented, and functional.
	- A large standard library and third-party package ecosystem through PyPI.
	- Cross-platform implementations and tools.
	- Interactive use through a REPL, notebooks, or the command line.

3. **What are Python's advantages and disadvantages?**

	**Advantages:** easy to learn and read, quick to develop with, broadly supported, and equipped with extensive libraries and community resources.

	**Disadvantages:** often slower than compiled languages for CPU-intensive work; can use more memory; dynamic typing may allow some errors to appear at runtime; and the Global Interpreter Lock in standard CPython can limit parallel execution of Python bytecode in threads. Other implementations and newer CPython builds may differ.

4. **What are the major Python versions?**

	Python has had major release series including 1.x, 2.x, and 3.x. Python 2 reached end of life in 2020; new projects should use Python 3. A version such as `3.14.7` means major version 3, feature release 14, and maintenance release 7. For compatibility, check the versions supported by your project and dependencies.

5. **What is the most stable Python version?**

	There is no single version that is best for every project: choose a supported release compatible with your dependencies. As of September 26, 2026, Python.org lists **Python 3.14.7** as the latest stable release. Python 3.15 is still a pre-release at that date. Check [Python downloads](https://www.python.org/downloads/) for the current release.

6. **What software tools are commonly used to develop Python programs?**

	- **Editors and IDEs:** Visual Studio Code, PyCharm, IDLE, and Spyder.
	- **Interactive work:** JupyterLab and Jupyter Notebook.
	- **Interpreter and packages:** CPython, `pip`, and virtual environments (`venv`).
	- **Quality and testing:** `pytest`, `unittest`, Ruff, and mypy.
	- **Version control:** Git.

	A typical setup uses an editor, a supported Python interpreter, and a virtual environment for each project.

7. **What file extension is used for Python source files?**

	Python source files use `.py`, for example `main.py`. Compiled bytecode may be cached in `.pyc` files. Jupyter notebooks use `.ipynb`.

8. **Name 10 prominent applications or services that use Python.**

	Python is used in parts of many large products; that does not mean the entire product is written in Python. Examples commonly associated with Python use include Instagram, YouTube, Dropbox, Spotify, Reddit, Pinterest, Quora, Netflix, Uber, and Google services. The exact languages and components used can change over time.

## How Python Works

11. **How does Python work internally?**

	In CPython, the usual sequence is:

	1. The interpreter parses source code and checks its syntax.
	2. The source is compiled to Python bytecode, which may be cached in `__pycache__`.
	3. The Python virtual machine executes the bytecode.
	4. Objects are managed by Python's memory-management system, including reference counting and a cyclic garbage collector in CPython.

	This describes CPython; other Python implementations may work differently. Python is often called interpreted because execution is managed by a runtime, even though CPython also compiles source to bytecode.

12. **What is Python's architecture?**

	A simplified view of CPython is:

	- **Language and syntax:** Python source code and its grammar.
	- **Parser and compiler:** turn source into an internal representation and bytecode.
	- **Python virtual machine:** runs bytecode and implements language operations.
	- **Runtime and object model:** provide built-in types, functions, exceptions, and memory management.
	- **Standard library and extension interface:** provide reusable modules and ways to connect to native code.

	The operating system and hardware sit below the interpreter and runtime.

13. **What is indentation in Python, and why is it used instead of braces?**

	Indentation is the leading whitespace that groups statements into blocks. Python uses indentation as part of its syntax instead of requiring `{}` around blocks. A colon introduces a suite, then consistently indented statements form that suite:

	```python
	if temperature > 25:
		 print("Warm")
	else:
		 print("Cool")
	```

	Use four spaces per indentation level, as recommended by PEP 8. Indentation makes block structure visible, but inconsistent indentation causes an `IndentationError`. Python still uses colons in constructs such as `if`, `for`, `while`, `def`, and `class`; semicolons are generally unnecessary.

## Core Language Concepts

15. **What are variables in Python, and how do they differ from variables in other languages?**

	A variable name is a reference bound to an object. Assignment creates or changes that binding:

	```python
	count = 3
	count = "three"
	```

	Python is dynamically typed: the object has a type, and a name can later refer to an object of a different type. This differs from statically typed languages, where a variable is commonly declared with a type that constrains later assignments. Python remains strongly typed: operations that are invalid for an object's type generally raise an error rather than silently converting it.

16. **What are Python's data types, and how do they compare with other backend languages?**

	Common built-in types include:

	- **Numbers:** `int`, `float`, and `complex`; `bool` is a subtype of `int`.
	- **Text:** `str`, an immutable Unicode string.
	- **Sequences:** `list` (mutable), `tuple` (immutable), and `range`.
	- **Mappings and sets:** `dict`, `set`, and `frozenset`.
	- **Binary data:** `bytes`, `bytearray`, and `memoryview`.
	- **Other values:** `None`, used to represent the absence of a value.

	Like other backend languages, Python has numbers, strings, collections, and user-defined classes. Its built-ins are dynamically typed, and collection types such as lists and dictionaries can hold values of different types. Type annotations can document and help tools check expected types, but Python does not enforce most annotations at runtime by default.

17. **What are functions in Python, and how do you define and use them?**

	A function is a reusable block of code. Define one with `def`, give it a name and parameters, and optionally return a result with `return`:

	```python
	def greet(name: str, greeting: str = "Hello") -> str:
		 """Return a greeting for a person."""
		 return f"{greeting}, {name}!"


	message = greet("Mina")
	print(message)  # Hello, Mina!
	```

	In this example, `name` and `greeting` are parameters. The call supplies the argument `"Mina"`; `greeting` uses its default. A function without an explicit `return` returns `None`. Type annotations describe expected types for readers and tools, but normally do not perform runtime type checking. Python functions are values: they can be assigned to names, passed to other functions, and returned from functions.

18. **What types of functions, parameters, and arguments are there in Python?**

	**Common function categories:**

	- **Built-in functions:** provided by Python, such as `len()` and `print()`.
	- **User-defined functions:** created with `def`.
	- **Lambda functions:** small anonymous functions written with `lambda`.
	- **Methods:** functions associated with objects or classes.
	- **Recursive functions:** call themselves.
	- **Generator functions:** use `yield` to produce values over time.
	- **Asynchronous functions:** declared with `async def` and typically use `await`.

	**Parameters** are names in the function definition; **arguments** are the values supplied when calling the function. Python supports positional-only, positional-or-keyword, keyword-only, default, variable positional (`*args`), and variable keyword (`**kwargs`) parameters.

	```python
	def describe(name, /, greeting="Hello", *, punctuation="!"):
		 return f"{greeting}, {name}{punctuation}"


	describe("Mina")                         # positional argument
	describe("Mina", greeting="Welcome")     # keyword argument
	describe("Mina", punctuation=".")        # keyword-only argument
	```

	Here, `name` is positional-only because it appears before `/`; `punctuation` is keyword-only because it appears after `*`. Default values should generally be immutable; mutable defaults can be shared between calls.
